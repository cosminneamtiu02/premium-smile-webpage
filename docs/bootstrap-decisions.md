# Bootstrap Decision Log — 2026-04-24

Record of the `project-bootstrap` run that converted the full-stack template into the
Premium Smile presentation-site scope. Generated by the adapted-cleanup variant of the
skill: no formal `graphs/<SLUG>/` artifact; user stated requirements verbally and
approved the decision matrix before execution.

## Input

**Project scope (verbal):** Presentation website for a dental clinic. Requirements:
WCAG-level accessibility, i18n driven by browser default (English / Romanian),
responsive layout across phone / tablet / notebook / desktop, color-scheme theming,
Storybook organized by component tier (atoms / composites / pages). Explicit cuts:
"no error codes, no nothing." CI/CD kept light; hosting target not yet chosen.
